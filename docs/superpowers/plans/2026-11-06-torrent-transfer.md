# 自动转移做种完整迁移计划

目标：将原 TorrentTransfer 的设置、源种子读取、过滤／目录转换、暂停添加、目标校验、可选启动、保留文件的源任务移除、原转种历史和通知迁移到 Go，并提供 React 审核、停止与未知结果核对。

沿用已有 Go 元数据解析、下载器协议、PT 保护、跨进程锁和业务通知。先完整接通模块，再集中运行行为测试；阶段提交的编译／静态检查不作为模块完成或实际转移成功的证据。

- [x] 核对原配置和完整阶段，建立种子文件读取、Tracker 恢复、精确哈希和目录映射核心。
- [ ] 实现暂停添加、校验和启动的原生协议，核对 v1／v2／混合种子的实际目标支持与任务标识。
- [ ] 持久化每个源／目标任务实例、动作意图、原回执和跨周期占用；不自动接管未知添加、校验、启动或源任务移除。
- [ ] 接通配置与生命周期、原五段 cron／一次运行、逐请求范围复核、停止、旧转种历史和原消息通知。
- [ ] 提供 React 目标审核、独立启动／源任务移除确认及原编号核对。
- [ ] 完整模块后集中测试、独立审查和正常 Go 进程验收；提交推送并更新整体进度。

设计约束：保持原始 info 字节不变，补 Tracker 不重编码 info；只读取审核目录内、内容匹配源任务的种子；排除规则维持旧行为，目录映射匹配完整组件。暂停添加、校验、启动、源任务移除分别记录意图；目标完整性未确认不能启动，源任务移除复用 PT 保护且保留文件。无源／目标任务与文件证据的旧历史不自动扩大为执行许可。

第一阶段暂不接入生产调用者或后台执行。真实下载器版本、文件布局、v2 任务标识和跨端校验语义在协议阶段进一步核对，不以元数据可解析代替目标实际支持。

第一阶段记录：新增元数据修复与只读根、完整组件目录映射和原配置读取；回归夹具已写，按用户指示暂不运行行为测试。文件与完整种子哈希绑定，原种子内容不写回。尚未接入后台、客户端或 React，不能以核心包代替模块完成。阶段检查为 Go 编译与静态分析。

兼容决定：原 qB 标签是包含匹配，Transmission 是列表成员匹配，目录排除是前缀匹配。第一阶段保留这些实际排除规则，包括旧空标签项的效果，避免升级后增加转移候选；路径转换单独采用完整目录组件。协议阶段必须提供原始 qB 标签字符串，不能靠重新拼接标签改变筛选语义。
