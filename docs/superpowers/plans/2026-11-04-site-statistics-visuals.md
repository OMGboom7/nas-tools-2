# 站点统计图表和 PNG 导出

**目标** 在现有 React 统计页接管旧页面的总量、按日和区间流量、单站趋势、做种分布和统计图片。

**设计** Go 从现有 SQLite 历史按站点地址计算流量增量，保留应用时区和十进制字节数。React 复用已授权的统计快照和历史。PNG 在浏览器内生成，按明确选择筛选和排序，默认用占位文字替代站点名和用户名。

- [x] 在 Go 增加只读流量接口，覆盖选定日期及最近一周、一月、一年，复用旧历史算法和当前统计范围。
- [x] 在 React 添加总量、日期切换、区间比较、单站趋势和做种分布，保留表格明细。
- [x] 在 React 预览及下载 PNG，保留旧排序选择，隐藏字段在绘图前剔除。选择为空时禁止导出。
- [x] 整批集中验证字节精度、同名站点、无数据、只读权限、导出遮盖及真实浏览器下载。核对退出指标。
