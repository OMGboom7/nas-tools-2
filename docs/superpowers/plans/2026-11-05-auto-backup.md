# 自动备份迁移计划

保留旧 AutoBackup 的配置、完整和精简 ZIP、单次与五段周期、目录及保留数量。在 Go 独立运行模式使用原 SQLite 的一致性快照。ZIP 发布后才允许处理已知旧备份。旧手动下载入口使用同一份归档逻辑，恢复作为独立的离线写入流程迁移。

- [x] 在 autobackup 包实现一致性快照和旧 ZIP 结构，保留未知数据库内容。精简备份只从副本删除原九张表。
- [x] 对目录身份、归档发布、恢复回执和保留策略验证权限、冲突、失败与重启。旧备份按原样保留。
- [x] 接通旧插件安装、配置和状态以及 React 管理入口。将一次运行领取与执行记录同事务提交。停止和修改配置撤销授权。
