# Go 站点用户统计迁移

沿用已批准的 React / Go 迁移方向和当前分支。原实现为 `app/sites/site_userinfo.py`、`app/sites/siteuserinfo/`；这批以完整统计调用链为单位实现，完成后集中测试并提交推送。

- [x] 原生解析：12 类协议保留识别顺序、资料、流量、积分、做种分页及未读消息。
- [x] 抓取：同源 Cookie、代理／限流、编码、Go 浏览器、登录检测及有限分页；失败保留原统计。
- [x] 存储：兼容三张原表及 favicon；一次事务保留未知字段，提供历史、增量和做种读取。
- [x] 执行：手动、回执、并发 10、进程互斥、持久停止和配置检查；原调度、一分钟延迟及独立 /sta 接入。
- [x] 消息：原开关、显式内容读取范围、读取前未读数量、通知事务；回执不保存凭据／完整响应。
- [x] 界面与旧接口：React 统计与历史、后台范围、回执及停止；旧统计 API 由 Go 原生处理。
- [x] 集中验证及独立审查：统计 44、签到 48、总线 58、相关 HTTP 33、前端 341 均通过；真实 Chrome 会话、本机页面／通知／重启验收通过，静态与本机／Linux 构建通过。

实现边界、日志及早期失败记录见 [统计迁移记录](../../migration/site-statistics.md)。

边界：保留原 Python 生产调用者直到全项目切换验收；统计迁移并不等于用户等级排行规则管理迁移。Docker 全镜像验收仍等待用户自行启动 Docker。
