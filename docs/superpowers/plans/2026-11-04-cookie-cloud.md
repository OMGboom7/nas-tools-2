# CookieCloud 同步迁移计划

**目标** 将旧 CookieCloud 的配置、同步、一次运行、定时、记录、站点新增和更新接入 Go 与 React。

**设计** 沿用 `plugin.CookieCloud` 配置和 CookieCloud 原解密读取接口。Go 根据当前站点目录匹配 Cookie，检查原连接后在 SQLite 事务发布更新和收据。React 只显示脱敏配置和状态，接管定时或手动执行前展示原接收方。

- [x] 配置保留未知值，兼容三种过滤模式和旧 cron。连接测试沿用服务端解密请求，无重定向。
- [x] 同步检查原连接、保留可用站点并新增目录支持的站点。按实际接收方限制 Cookie 范围，保留旧站点字段。
- [x] 通过持久执行编号、共享执行锁和事务提交支持并发、停止与重启回查。设置变化撤销旧授权。
- [x] 接通 React、原插件目录和旧配置／状态／记录入口，完成集中测试与本机浏览器验收。
