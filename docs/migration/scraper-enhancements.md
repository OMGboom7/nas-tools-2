## 中文演职员

电影/剧集的 `credits` 和 `credits_chinese` 同时启用时生效，仍只处理原 TMDB 电影/剧集 ID 的 Director/Acting 人员，保留 TMDB 人员 ID、排序、原图片和个人链接。先用原标题/本地化标题、年份和种类筛选豆瓣媒体，再核对详情、可用 IMDb 身份与演职员；多个候选、已知截断结果和身份冲突不取第一条。电影保留旧年份 ±1 范围，剧集要求同年；匹配依据不是跨库绝对身份证明。

豆瓣签名、固定域名与只读协议从已有 Go 订阅解析抽成共用客户端；不向豆瓣发送 TMDB/API 用户凭据。人员用完整姓名或 TMDB 已核验 person ID 的别名匹配，允许姓/名词序颠倒及去音调，不用子串把 Li 匹配进 Liam。重名或冲突行拒绝，不把另一人的名字写进 NFO。唯一豆瓣匹配可采用有明确“饰”前缀的角色；否则保留 TMDB 角色。

豆瓣不可用/无法匹配时回退 [TMDB 人员详情](https://developer.themoviedb.org/reference/person-details) 的别名和原姓名。繁简转换使用固定 `github.com/longbridgeapp/opencc v0.3.13` 的标准 t2s 配置与内嵌词典，不依赖 Python、C/OpenCC 动态库或运行时下载；不是逐字复制 zhconv 的区域词表。整个增强读取有 75 秒预算、最多 128 个独立 TMDB 人员请求，重复 ID 共享本次缓存；有未完成/歧义项则保留原名并回执 partial，不宣称中文化完成。

## 缺图回退与执行范围

同时启用 `episode_thumb`/`episode_thumb_ffmpeg` 且 TMDB 没有该集 still 路径时，才派生本地截帧项目。已有图片（含外来链接）直接保留，不启动解码器。上游已有图但下载失败沿用旧语义，不暗中改为读视频。截取固定第 181 秒，不对短视频偷偷改用第 0 秒。

只读消费者必须来自已完整完成的原入库媒体。Linux/macOS 固定打开目标根及父目录，核验内容 SHA-256、节点身份、大小、mtime/ctime/链接数和符号链接绑定；软链接模式打开原已审批源节点。解码前后范围必须一致，恢复 mtime 不能掩盖同节点内容变化。不是按一个普通绝对路径让子进程重新找文件。

FFmpeg 通过 Go 的直接进程参数调用，继承一个只读常规文件到 FD 3；不调用 shell、不把用户文件名拼成参数、不继承凭据/FFREPORT 环境。使用 [fd 协议及协议白名单](https://ffmpeg.org/ffmpeg-protocols.html#fd)，仅允许 fd/pipe 和受限媒体容器，不允许 HTTP/file/concat 清单扩展到其他资源。输出只到 stdout，不接受输出路径或覆盖参数；单次 30 秒、单线程、最大 8 MiB 输出、最大 1280×720 缩放框，退出/超限/取消终止并等待独立进程组，stderr 不进入错误或日志。

输出须通过完整 JPEG 内容校验，然后才经已有私有暂存意图和防覆盖发布。失败不修改视频、不撤销媒体历史、不重跑入库或解码；回执保存不确定时保留已发布图片及 writing/partial 证据。字幕仍等待本轮刮削处理。

## 构建与剩余范围

Go-only 候选镜像加入 Alpine FFmpeg 原生包，并从固定 Go 依赖复制 OpenCC、da、cedar-go 许可证，不引入 Python。Alpine 3.21 包为 6.1 系列，其上游源码已有 fd 协议；实际镜像构建和 Linux/NAS 文件系统仍须另外验收，不能由 macOS 模拟测试推断完成。

纯 Go 转换及 Go 进程管理不等于解码器也用 Go 编写。FFmpeg 是现有业务所需的原生外部程序；缺失或不兼容明确失败，不启动 Python。保留已审核的旧用户选项，未重放此前 blocked/partial/running 回执。媒体库遍历、强制覆盖、完整蓝光/远程、其他 Python 业务和最终生产退出继续待迁移；整体仍粗估 50–60%。
