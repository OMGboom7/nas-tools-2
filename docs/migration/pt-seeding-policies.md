# Go PT 约束登记与执行保护

本批迁移的是已有下载任务的做种证据读取、源资源约束登记，以及本版本 Go 的停止、删除和下载来源移动整理保护。它不是完整 PT 自动化；后续 [Transmission PT 提交模块](transmission-pt-admission.md) 已在配置级明确授权和远端停种设置验证下接通部分带正值要求来源，其他情况仍拒绝，Python 尚未删除。

## 约束与证据

最低累计秒数、最低分享率和 HR 均为可空字段，未知不等于 0 或 false。多个源资源约束必须全部满足，后登记的宽松或未知约束不会替换原约束。HR 标记或未知均拦截；分享率和时间达标不等于站点账户 HR 已解除。本批没有 HR 解除、删除或降低约束接口。为避免把索引器摘要当账户级证据，当前接管一律保留 HR hold，登记前必须单独确认其持续拦截的影响。

qBittorrent 读取单一完整 hash 的 `torrents/info?filter=all&hashes=...`，仅使用 `seeding_time` 与 `ratio`。Transmission 按协商协议读取 `secondsSeeding/uploadRatio` 或 `seconds_seeding/upload_ratio`。缺字段、负数哨兵、错误身份、重复任务、未知状态、检查中或未完整下载不能证明满足约束。不用当前时间减下载完成时间冒充累计做种时间。

## 管理员接管

从 React 搜索结果选择“接管现有任务的 PT 约束”，填写准确下载器 ID 与现有任务完整 hash。服务端只读获取当前用户未过期的缓存源资源，解析磁力或原 torrent 的真实 hash，与远端准确任务匹配，不能由客户端提交修改后的阈值。审核指纹绑定操作者、源资源、下载器整行配置、源声明及原约束集合；登记时重新审核并在 SQLite 事务中检查配置和集合。

分别确认不可降低约束、旧 Go/Python 执行器已实际停止，以及未知/HR 持续拦截。登记只追加到 `GO_SEEDING_POLICIES`，不向下载器添加、停止、删除或修改任务设置。持久化记录不包含私有下载链接、站点 Cookie 或下载器密码，仅存来源摘要及不可逆配置/来源指纹。响应不确定只读刷新，不自动重发。

下载页提供独立只读查询；未登记明确显示为“不是无需做种证明”。当前证据仅供展示，实际执行重新读取。管理员入口要求纯 Go 模式与当前管理员身份；登记另外核对下载管理权限。现代及兼容下载写入路由均核对当前账户的下载管理权限，而不只验证 JWT。

## 执行边界

本版本通用停止/删除、下载完成监控的停止/清理任务、下载来源移动执行及移动/发布/清理恢复使用同一下载器 ID/hash 跨进程锁。持锁覆盖远端操作或真实源文件移除，登记不能同时穿过执行窗口。移动执行中的后续验证也重新读取约束及计数；配置变化、证据缺失、锁不可用、阈值不足或 HR hold 均拒绝。

未登记的原任务保留既有行为，这不证明它没有 PT 义务。本模块不控制下载器自身全局或每任务自动停种、其他外部客户端、旧版本执行器，也不据此保护无下载来源关联的任意文件系统整理。不能仅凭本模块就开放自动带正值要求的下种。后续还需将不可变来源约束与自动提交及远端停种设置生命周期接齐，补站点账户级 HR/达标验证与人工恢复机制，再验收真实下载器及生产镜像。

## 验证范围

使用临时 SQLite 与模拟网络验证两个下载器协议、完整身份/未知值、累计计数边界、只读不建表、追加及集合 CAS、重启恢复、私有字段不公开、配置变化、现代/兼容权限、任务控制及移动/恢复共享锁；前端验证只读请求、独立确认、跨任务拒绝和丢失响应不重发。没有操作真实下载器或部署生产服务。

集中验证通过：Go 全量测试（HTTP 服务约 69 秒）、`go vet ./...`、CGO 禁用的 Linux amd64 静态构建；策略、持久化、两个下载器、搜索缓存及整理包的完整 race 测试，以及 HTTP 策略/权限、下载监控/整理、Transmission 设置、订阅 RSS 相关 race 回归（约 75 秒）。前端 115 项测试和 TypeScript/Vite 构建通过。入口包约 512 kB，仍有非阻塞体积提示，未提高阈值隐藏。Python 退出检查仍为 360 个源码文件、13 处 Go 旧接口调用、75 处旧代理/运行时引用、45 处容器 Python 引用。

整体迁移仍保守粗估 50–60%，不是按新增文件数计算；PT 自动提交、部分高级订阅/媒体/云端能力以及最终 Python 运行时、镜像和代码清理仍未完成。
