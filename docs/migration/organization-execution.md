# Go 原生整理：本地复制任务

这是整理迁移的执行批次，不代表完整整理、同步和自动入库已经完成。保留旧 Python 实现，待所有保留能力和生产切换验收后再删除。

## 已实现范围

- 管理员在 React“整理预览”页扫描现有配置目录，核验媒体命名、大小门槛和目标冲突。
- `POST /api/v1/organization/jobs` 使用来源/目标 ID、相对路径、`mode=copy` 和已审核预览的 `fingerprint`，重新生成预览并核对指纹；变化时返回 409，不保存旧计划。只保存可规划项，先媒体后附件。
- 创建任务只写当前 `user.db` 的新增账本，不创建媒体目录、不复制文件。`GET /api/v1/organization/jobs` 返回最近 30 个任务，`GET /api/v1/organization/jobs/{id}` 可读取任意已知任务 ID。
- 管理员另行确认文件已下载完成，调用 `POST /api/v1/organization/jobs/{id}/execute`，JSON 为 `{"confirm":true}`。任务创建、页面加载、刷新和错误处理都不会自动执行。
- 执行重新核对完整配置摘要、启用来源/目标、物理根身份以及每个源文件的设备/节点身份、大小和纳秒修改时间；源文件至少 30 秒未修改。目录选择沿用默认 150 MiB 或 `media.min_filesize` 门槛，明确单文件选择沿用旧行为不受该大小门槛约束。
- 只在 Linux/macOS 且关闭旧后端的模式开放执行；其他模式仍可预览，不回退 Python 转移。部署时必须另行停止旧 Python 整理/同步执行器：`NASTOOL_DISABLE_LEGACY=true` 本身不能停止独立 Python 进程。不要因此把尚未验收的候选运行时直接替换生产环境。

## 写入、去重与恢复

账本为 `GO_ORGANIZATION_JOBS`、`GO_ORGANIZATION_ITEMS` 和 `GO_ORGANIZATION_TARGETS`，位于既有 `user.db`。使用原应用的迁移前备份，不另起空库绕过旧数据。目标身份与相对路径的持久唯一预留跨 handler/重启保留；没有超时租约，也不因断线自动释放。单项用数据库状态比较更新抢占，只有一名执行者可开始。

文件操作从已核验根目录的固定描述符逐层打开目录，拒绝链接祖先、链接源文件和非普通文件，不把客户端任意路径用于写入。先将源内容复制到目标目录下专属 0700 暂存目录，保留普通权限位和修改时间，计算 SHA-256 并同步文件/目录；再保存设备/节点、私有暂存目录和父目录身份及摘要凭证。通过目标侧硬链接原子发布已复制的暂存文件，目标已存在时失败，绝不覆盖；这不是把源文件硬链接进库，源和目标有独立内容副本。暂存引用保留到账本提交后，避免节点复用被误认作本任务的发布。当前要求目标文件系统支持硬链接和文件/目录同步，不支持时明确失败，不退化为覆盖式复制。

发布后再次核对目标身份和全部内容摘要，媒体成功状态与 Python 兼容的 `TRANSFER_HISTORY` 在同一数据库事务提交；附件不重复生成媒体历史。历史字段保留“复制”“手动整理”、核验的媒体类型、标题、年份、分类、季集及源/目标完整位置。事务失败时保留文件和发布凭证，不假装复制失败后重新执行。只有提交后才清理经过身份核验的本任务私有暂存内容；不清理源目录或任意未知文件。

| 单项状态 | 含义与允许动作 |
| --- | --- |
| `planned` | 尚未执行。整个任务均为此状态时可明确取消，保留任务记录并释放目标预留 |
| `running` | 已开始，可能仍执行或已中断。不能凭时间判断停止，不能自动重跑/取消释放 |
| `prepared` | 完整复制凭证已保存，未必已经发布。只允许基于正向证据核对结果，不自动重新复制 |
| `completed` | 发布身份/内容已核验，成功状态及媒体历史已提交。重复执行跳过该项 |
| `cancelled` | 未执行任务已取消，不再执行 |

`POST /api/v1/organization/jobs/{id}/reconcile`（`{"confirm":true}`）只核验已保存发布凭证：私有暂存引用、设备/节点、根/父目录身份和 SHA-256 必须相符，才补交状态和历史。仅存在同名、同大小甚至同内容的其他文件不是成功证据。未发布、缺少完整凭证、损坏、替换或配置变化均保持占用/待核对，不自动删除暂存文件，也不返回“从未执行”的猜测。已核对完成的部分不会重复制；剩余 `planned` 项可由管理员再次明确确认执行。`cancel` 只适用于全未执行任务。

## 验证与后续缺口

测试使用临时本地文件和 SQLite、模拟 TMDB 请求，覆盖真实字节复制、源不删除、目标不覆盖、媒体先于附件、身份/配置变化、链接路径、活跃文件、预览失效、管理员权限、兼容运行模式拒绝、并发单次执行、账本重启、历史事务失败和正向恢复。前端接口测试覆盖持久任务读取、创建不执行、执行失败不重试及刷新不执行；TypeScript/生产构建通过。尚无真实 NAS 文件系统、真实下载器完成状态、浏览器操作流程或生产容器联调证据。

后续仍必须迁移移动/硬链接/软链接模式、完整蓝光与远程转移、增强命名/媒体元数据、未识别记录和手动指定身份、半写文件/下载器完成信号、目录监控/自动整理、业务事件/通知以及明确的负向人工处置和未发布暂存恢复。当前复制不保留所有扩展属性/ACL；静默间隔和人工勾选不能代替下载器实际完成核验。整个 Python 退出目标仍未完成。
