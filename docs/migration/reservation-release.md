# 旧目标预留的独立释放

整理、整盘、远程目标、元数据未决输出及历史／媒体删除范围的旧占用，通过独立的 Go／React 账本审核释放。不是删除文件或恢复副本的附带效果，不采用未知内容为旧任务补造成功证明。

## 权限和影响

- 仅纯 Go 模式管理员可用；混合运行明确拒绝，不回退 Python。
- 以整理任务、已有库刮削、恢复对象处置或历史／媒体删除批次的精确编号为起点。按已存路径的保守大小写／Unicode 规范化、已存相同根身份的不同名字、父子范围、原历史／未知关联及持久父子关系，计算完整连通范围；同一旧多库批次和当前刮削周期的全部兄弟必须一起审核，不只释放一页或成功子集。冻结身份别名只使用原账本证据，不探测或重新采用当前挂载。
- 审核不读取媒体、探测云账户或要求旧配置根在线。它只证明当前账本快照，不证明文件存在、缺失、已发布、完整或可覆盖。
- 已有库媒体的 `InputRoot` 按原任务中冻结的根编号解析，不能把编号误当路径；普通文件、软链接输入与完整整盘中各叶子的授权输入都参与删除保护和占用关联，不靠当前配置重新解释旧绑定。
- 须分别确认完整关联范围、独立释放、永久关闭旧任务及关联、缺少文件证明的风险、未来新任务／已授权自动流程可能重新处理，以及外部写入器已实际停止。勾选不代为停用 Python、其他实例或下载器。
- 释放不删除、移动或恢复文件，不清理暂存／隔离／元数据备份，不修改旧媒体、转移历史、黑名单、同步去重或未识别行的成功状态，不操作下载器或调用旧插件。
- 旧任务、整个旧多库批次、当前刮削周期全部相关子任务及相关删除任务永久关闭。原逐项状态和凭据保留；待处理的未知记录关联标记取消，不将未知记录标 Y。原批次父记录另有完整留档后关闭，不能通过重复旧预览或旧恢复授权重开。
- 未来周期的配置授权不因关闭历史工作清单而扩大或自动撤销。释放可能使后来已授权的流程不再被旧占用阻止，但每次仍须建立新任务、重新核验内容并使用原发布／防覆盖规则。释放不是覆盖未知文件或重新执行旧动作的许可。

## 一次事务和永久回执

1. 管理员只读预览完整范围、精确占用／执行授权、全部任务编号及原始行数量。历史路径仅展示每任务最多 100 项样例，不把样例当工作范围。
2. 取得整理、入库补充、已有库发布、远程命名空间和所有旧任务／多库批次的既有跨进程锁；忙时拒绝，不等待后抢占。加锁后再次读取整个范围，新增关联或账本变化整体拒绝。
3. 执行请求只带起点、服务端生成的稳定随机请求编号、原因、审核指纹及独立确认，不接收客户端任务清单、路径、内容证明或要删除的任意表名。
4. 单个事务内再次计算完整快照，关闭全部相关旧权限，逐行删除精确的目标／整盘／远程／已有库输出占用，并取消所选旧任务的 pending 未知关联。全部列和值参与精确比较；任一步失败全部回滚，不留下部分关闭或部分释放。
5. 入库补图的隐式未决输出和已停止媒体删除的范围由专门的留痕释放标记解除，不抹掉旧未决输出／删除凭据。标记只在已关闭的精确当前账本签名与完整释放回执均有效时起效；旧行变化、标记孤立或回执损坏重新阻止后续工作，不能以宽泛的“旧任务已关闭”绕过不确定占用。
6. 事务保存原始 SQLite 完整行和稳定回执；保留 NULL、文本、int64、实数、BLOB 及额外列。完整私有定义、配置／内容凭据不返回浏览器。回执与原始记录长期保留，不用文件名推断归属。

没有后台释放 worker、启动重放、过期自动释放或网络错误重试。React 在提交前保留稳定回执编号；失败清空授权但保留编号，可只读找回较早回执。同一已提交请求仅返回原回执，不再扫描存储或释放后来新建任务的预留。原有媒体／恢复对象删除入口仍是另一次独立审核和授权。

只读起点列表每页 30 条，回执列表显示最近 30 条，也支持精确编号查询。完整关联审核目前沿用每类最多 5,000 份整理／刮削定义的底座限制，总计最多 10,000 个所有者、200,000 个历史路径及派生身份别名索引项、每份定义最多 2,048 个根映射、50,000 项占用／授权及 50,000 行原始记录，私有定义最多 64 MiB；别名去重和构建受取消约束。超限或损坏关联整体拒绝，不保存截断清单。更大存量账本的索引化、分页图遍历及实际性能仍待验收。
