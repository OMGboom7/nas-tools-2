# 媒体展示缓存与同步进度

2026-10-16：迁移探索媒体卡片的登记簿标记，以及手动/定时同步的真实持久进度，继续使用原 `media.db`。不引入新的媒体服务器协议，不调用 Flask，不把缓存查询接入下种判断。

## 展示缓存

- `POST /api/v1/library/sync/lookup`：已登录用户可批量查询 1–200 个 `{tmdbid,title,year,type,season?,episode?}`，type 为 movie / show。只读本地数据库，不访问媒体服务器、不创建订阅或下载，也不返回本地路径、凭据或原始配置。
- 在同一只读事务内读取 Go 快照元数据与对应条目。电影/剧集类型独立；有 TMDB ID 时只匹配这个 ID，没有 ID 时才按精确标题及可选年份匹配。不能用同名、不同提供方 ID 的条目假装命中。有 ID 的匹配沿用原逻辑，不因译名/年份差异丢失相同身份。
- 显示范围与服务器配置摘要绑定；未曾 Go 同步、切换服务器、配置变化或读失败均为 unavailable / unsynced / scope-changed，不返回虚假的“缺失”。不把没有来源的旧 Python 行自动认证为 Go 快照。
- 结果为 present / not-recorded / unavailable。present 只是所选库上次快照有记录；not-recorded 不是当前媒体服务器缺失，未选库也可能已有资源。即使当前配置匹配，缓存仍可能陈旧。
- 可选季/集查询按实际记录匹配，保留第 0 季/集；仅传集时按第 1 季。多个版本的集号合并去重，不凭一集声称整季完整；无季/集选择时允许显示剧集条目记录，不声称集数完整。异常集号/JSON、过多同身份版本或范围不一致返回未知，不能自动修复数据。
- 探索 `POST /api/v1/discovery` 附加共用的 cache 元数据与每卡片 cachedPresence；React 明确标记“非实时”“不代表全集”“未记录不代表当前缺失”。原 subscribed 字段、订阅按钮和下载/订阅实时 Inventory 均不改变。缓存故障不阻断推荐内容。
- 原库增加 SERVER / ITEM_TYPE / TMDBID 及 TITLE / YEAR 查询索引。读取不清表，不额外引入进程级过期缓存；重读即看到最近完整提交的代次。

## 持久进度与成功证据

新增 `GO_MEDIASYNC_ACTIVITY`，关联手动或定时运行 ID、原范围/操作者、阶段、内容页数、已完成库数、影视数、展开剧集数、时间、终态及成功快照代次。

- 真正开始远端采集前先登记 collecting，不在只读页面加载、审核、计划启用时伪造运行。逐页验证成功后增加内容页数，完整处理影视及其剧集后增加影视/集计数；每秒合并写入，阶段/库变化和准备提交时强制保存。失败时可能保留最近检查点，不代表已完成全部响应。
- 阶段依次包含 libraries、items、episodes、library-complete、publishing。publishing 仍是 collecting，不等于成功，不用尚未知道的总项目数计算虚假百分比。
- 手动/定时发布前核验原活动 ID、类型、范围、准备提交阶段、全部库计数及影视/集计数与真实待提交内容一致。快照、旧统计、定时运行成功回执及活动 completed/快照代次同事务提交；活动缺失、写入被忽略或失败都会回滚快照。
- 停止、替换、暂停定时授权在同事务终结对应进度；中途返回的旧结果不能变成 completed。采集失败/取消保存 failed / interrupted，保留旧缓存及真实已记录计数，不显示 100%。
- 持有共用执行锁后才能把遗留 collecting 记录标记 interrupted。查询接口不靠时间或状态行认定进程已经停止；collecting 也可能是尚待执行器核实的中断记录。旧版本无活动记录的定时失败/恢复可保留，但新成功必须有完整活动回执。
- `GET /api/v1/library/sync/progress`：Go-only 管理员只读最近 50 次活动。不请求媒体服务器，不重试同步。React 支持只读刷新/观察；手动操作期间自动观察，结束后再读最终回执，取消观察/换会话会取消观察请求，不取消或启动业务任务。

## 兼容接口与未完成范围

- `POST /api/v1/library/sync/status`：原 mediasync_state 的统计文案由 Go 快照生成，标记展示用途及配置不匹配，不代理旧服务。
- `POST /api/v1/system/progress`，表单 `type=mediasync`：返回真实最近活动 text/state/enable；采集、发布准备或失败时 value=0 且明确不可定百分比，只有 completed 且有快照代次时 value=100。其他进度类型返回 501，不冒充已迁移，也不退回 Flask。
- 上述管理接口要求管理员；展示查询与探索为已登录用户。请求体、身份和批量数量有界，无鉴权不读取登记簿内容。
- 后续已接入 [原生详情/季集及实时播放入口](media-details.md)，复用本模块展示查询。旧 `start_mediasync`、SSE `/stream-progress`、其他媒体/插件展示使用方仍未全部迁移，不能以新增探索标记或查询 API 为由删除。Go React 不依赖这些旧入口，新同步有独立明确确认。
