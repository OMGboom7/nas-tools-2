# 远程已有媒体库刮削

后续另有 [恢复对象独立永久处置](recovery-object-disposal.md)。它需要全新审核、唯一副本风险与关闭旧任务的独立授权；一旦关闭，原刮削／恢复权限不复用。下文的双份长期保留及不自动清理仍是本刮削流程的默认行为，原恢复确认不授权删除副本。

本批延伸已有库的 Go 持久流程，不伪造已完成入库任务，不写转移历史，也不删除、移动或覆盖视频。媒体库逐项显式选择本机、Rclone 或原生 MinIO；远程逻辑路径不能降级为同名本地目录。两种远程账户沿用显式配置及原账户／信任绑定，不引入 Python 或 mc。

| 模式 | 已有 NFO | 已有图片 |
| --- | --- | --- |
| `no_force` | 优先读取已有明确 TMDB 身份，只补缺失 | 保留 |
| `force_nfo` | 重新识别，只重写所选 NFO | 保留 |
| `force_all` | 重新识别，重写所选 NFO | 重写所选图片 |

## 审核、内容与发布

只读审核固定账户、根、相对选择／排除、设置和完整对象清单，不为扫描下载整个视频。创建时重新列举全部范围，迟到文件不自动加入。后台先声明原条目正在执行，再完整读取普通视频或整盘全部不可变载荷，将 SHA-256 内容凭证以比对更新写入该条目；只有此前已审核、未开始的清单能转入内容采用。未落账或中断条目不自动重新采用另一份内容。

清单不是内容证明。首次完整采用受明确独占命名空间／已停止全部外部写入器的约束；不支持把云端名称、大小、时间或 ETag 当本地 inode。采用以后，每次元数据发布前后都须重新核验媒体内容与清单。Rclone 链接对象及危险／歧义清单继续拒绝，不跟随到未授权来源。

覆盖前先保存 `writing` 意图与目标占用，在随机私有范围保存并核验原件、新件和绑定清单；缺失目标仍走不覆盖式发布。原件与新件均长期保留，不自动清理，也不因响应丢失删除任何目标或副本。MinIO 小元数据写入附加 If-Match／If-None-Match；Rclone 没有跨后端通用的目标 CAS，两者都不宣称本地原子交换语义。所有外部写入器必须实际停止，发布期间可能看到不完整内容。

只对生成的 NFO／JPEG／PNG 元数据写入。读取旧 NFO 上限 2 MiB，旧／新元数据及恢复上限 16 MiB；可恢复原先的零字节文件。远程清单沿用底层协议的 20,000 个目录／文件对象预算，整盘与工作清单还有原文档预算；不能将超限后的成功子集当整批通过。保留副本也会占用枚举预算，需要后续独立处置，不能为了通过测试自动删掉它们。

## 完整入口与回执

手动审核／创建、原生后台、旧 `media_path_scrap` 与 `media.scrap.start` 事件共用以上流程。媒体库刮削插件支持逐库存储方式、混合账户批次、仅运行一次及五段 cron；当前配置、设置、账户和授权世代都参与审核。远程读取／非原子独占和保留副本费用须重新分别确认，不能从旧 `ENABLED`、旧本地授权或保留参数推导。保存后才可创建后续批次；扫描中断不自动复用半份清单。

已有库与入库补图共享逻辑元数据的不确定占用，切换入口／重叠根不能绕过旧意图。取消、账户／信任／设置撤销会中断远程工作；已开始或不确定条目不随重启自动重放。影视身份、共享剧／季 NFO、图片验证和可定位 FFmpeg 缺图回退仍复用原生实现。蓝光按整盘及全部载荷审核，内部选择须明确扩展，禁止猜选 STREAM 片段或向盘内目录写元数据。

恢复先停止任务，逐输出重新完整核验原件、新件、清单及当前目标，并再次确认远程独占与副本费用。只读核验只补数据库回执，不重发云端写入；明确恢复只写回原内容，保留两份副本，不重跑刮削。恢复响应丢失时保存 `restore_running`，若后续完整核验已是原内容，只补回执，不再次写入。后来改变的目标、账户或副本均阻止恢复。

内容恢复不是对象存储 inode、版本 ID、扩展标签、ACL 或保留策略的复原承诺；服务端拒绝条件写入或保留策略时不得强行绕过。未知对象、缺失凭证与未完成暂存的独立处置仍是后续工作。

## 集中验证

整个模块完成后统一执行回归。最终不缓存后端全量通过（HTTP 1348.891 秒、整理内核 104.020 秒）；相关 HTTP 竞态通过（303.125 秒），整理／远程存储／解码内核竞态通过（118.972／21.997／9.081 秒）。静态检查、Linux amd64 无 CGO 静态构建和模块缓存校验通过；生产依赖不包含 `testing`、`httptest` 或私有测试服务。

隔离 Rclone CLI 只使用临时别名和空账户环境；MinIO 使用虚构账户、临时 CA 与内存 S3 协议夹具。真实 FFmpeg 只读取合成视频，覆盖尾部索引 MP4 的可定位读取。三模式／恢复／丢失回执、旧事件、混合定时批次、取消／撤销等相关远程用例均实际运行，没有跳过。集中回归还修正了自动识别将 `auto` 细化为电影／剧集时的账本兼容性，并增加根 ID、逻辑路径、身份及非法类型的反向验证；缺失历史表不被测试误判为新增入库历史。

前端 204 项测试、TypeScript 检查和生产构建通过，覆盖独立远程／覆盖授权、审核范围绑定、恢复和丢失响应不重发。主包约 595.63 kB（gzip 164.23 kB），既有超过 500 kB 的构建提示保留，不提高警告阈值。

真实云账户、MinIO 服务、NAS、浏览器及生产候选镜像尚未验收。用户选择自行启动 Docker，不由代理启动 Docker Desktop；以上实现不代表整个 Python 退出目标完成，也不提前删除旧实现。
