# Rclone 同步与下载完成整理（2026-10-21）

本批将已有 [Rclone 手动转移与恢复](rclone-manual-intake.md) 接入原结构直接同步、识别同步监控、下载完成持久批次及默认关闭的下载完成调度。仍然直接执行 Go Rclone，不调用 Python；不把其他 provider 或尚未开放的旧记录入口当作已完成迁移。

后续旧记录重新规划及旧 REST 重新识别／改名／自定义识别现由 [独立旧记录模块](rclone-legacy-intake.md) 接通；本页保留当时自动入库批次的验证范围和数字。

## 共用执行与数据兼容

继续使用 `rclonecopy`／`rclone`、旧 `Rclone复制`／`Rclone移动` 历史标签、固定的 `NASTOOL:<逻辑根>/<相对路径>` 以及原 YAML、`CONFIG_SYNC_PATHS`、下载器配置和用户数据库。不把远程目标作为本机目录解析、检查或创建；本地来源和未识别目录仍按本地权限与图约束核验。远程目的根只参加远程命名空间预留，不因同名本机目录形成假循环，也不降低本地来源重叠保护。

直接同步保留原相对路径和普通文件，不查询 TMDB，完整成功后只记 `SYNC_HISTORY`；旧同步历史继续抑制重做，不证明目标当前存在。识别同步与下载完成沿用完整媒体／附件组、真实身份选库、命名和蓝光整盘范围；不把未识别或冲突对象当原结构复制的替代成功。

所有实际转移复用同一私有副本、全量 SHA-256、持久发布意图、源隔离／清理、历史和入库事件链路。远程发布仍非原子，需独占命名空间；完整恢复副本和元数据暂存持续保留，空目录按后端能力或私有逻辑清单保存，读取及存储可能产生费用。后台执行并没有获得删除云端对象、重传不确定源或覆盖未知目标的权力。

## 授权与撤权

保存配置、预览或创建待执行批次不启用后台。启用同步／下载完成调度必须重新审核实际范围，并独立确认：停止旧执行器及会写来源／远程范围的外部程序、后台自动执行、独占远程命名空间与非原子可见性、保留每个任务的恢复副本及费用。移动、暂停下载任务、结果回写、任务记录移除及 Transmission 标签独占仍分别授权。

新授权持久化协议版本、目标根 ID、远程配置／执行文件／环境的组合摘要、空目录能力及确认时间。对外只返回不透明摘要与公共目标能力，不返回账号内容、配置文件路径或私有 Binding。每个后台转移凭证保存原操作者、授权世代、确认时间和触发来源。

启动和每轮观察重新核对账户配置、根及范围；实际写入前核对当前世代与原目标绑定，发布阶段和关键数据库事务也核验同一远程授权。暂停、更换世代、移除远程同意、切换账户／执行文件内容或配置变化阻止旧后台继续提交；不能靠旧 `ENABLED`、升级程序或撤销配置恢复授权。仅凭本地源的两次稳定快照也不会自动获得远程权限。

暂停请求不能将已经开始的文件系统步骤与数据库变成一个原子操作；当前步骤可能保留私有对象或源隔离记录，须读取原账本。原执行、`staging`、发布或下载器回写不确定时，重启和下一轮调度均不自动重放。

已有后台任务允许管理员在原任务入口重新独立授权正向核对／继续发布／继续移动；这是手动恢复，不重新启用旧后台授权，不改变原凭证的触发来源。原源恢复继续不依赖远程在线；`remote_closed` 和原源恢复终态可被人工忽略事件，但不变成整理成功、不释放目标预留或派发虚假回写。

## 下载器语义不降级

qBittorrent、Transmission 两种 RPC 和 Aria2 使用原生完整候选／逐文件完成证据、精确任务 ID、归属、路径映射、双次稳定观察和任务唯一批次。远程移动使用与本地移动相同的 PT／做种约束和停止状态核验；后台暂停前先存意图，响应丢失不再发暂停或继续文件整理。

全部媒体文件、附件及移动清理核验成功后，复制才增加“已整理”标签；远程移动只移除种子任务记录，始终保留所有剩余本地数据。Aria2 只移除完成结果记录，Transmission 继续要求标签整体写入的独占确认。结果操作先存独立意图，响应不确定只核对，不重发，不重跑转移；保留原有一次性业务通知、NFO／图片和字幕队列。

## React 流程

原结构同步预览展示远程约束，保存后在任务区独立确认。同步监控与下载完成监控展示本轮远程根／空目录能力及两项独立远程授权；手动下载批次执行也需独立远程确认，不借用保存时或后台的勾选状态。改变范围、会话、重新审核或请求完成／失败均清除本次同意；暂停／忽略／恢复原源不授予新的远程写权限。

## 验证与进度

模块整体接通后集中验证。真实 CLI 用例使用 Rclone v1.68.2、显式测试二进制、临时 `[NASTOOL] type=alias` 配置、空子进程环境和模拟下载器，不读取工作站账户。

- 真实命令覆盖原结构直接同步与识别同步、复制／移动、同步监控及下载完成批次／自动调度。qBittorrent、Transmission 旧版／新版 RPC 与 Aria2 各自验证暂停／停止状态、保留未选中数据、复制标签／移动只删任务记录、独立结果授权及重复轮询不重放。
