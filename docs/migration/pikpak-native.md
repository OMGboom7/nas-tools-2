# PikPak 原生 Go 下载器

旧 `app/downloader/client/pikpak.py` 实际实现账户登录检查、离线任务查询及离线链接提交；暂停、开始、删除、文件转移等方法原本为空。本模块将登录、任务列表、磁力提交迁移到 Go，不将原空方法伪装为成功，也不为失败的请求回退 Python。

## 请求与凭据

协议对照上游 [PikPakAPI](https://github.com/Quan666/PikPakAPI/blob/main/pikpakapi/__init__.py) 的账户挑战初始化、signin、`drive/v1/tasks` 及 `drive/v1/files`。这是非官方服务协议适配，不代表已完成真实账户验收。仅固定 HTTPS 账户和网盘域名可接收请求；账户密码仅用于登录，Bearer 仅用于网盘。客户端禁用重定向，限制响应大小、超时和分页数，所有上游错误均返回固定错误，不向接口返回密码、token、原始错误正文或带凭据地址。

支持原配置的可选 HTTP/HTTPS/SOCKS5 代理；没有协议前缀时按 HTTP 代理解析，非法地址拒绝，不静默绕过代理。显式代理使用独立克隆的标准 HTTP transport；无法配置代理的自定义 transport 会明确拒绝。验证挑战需要交互时停止，不跳转、不绕过；没有自动解验证码。短生命周期客户端不保存账户令牌到磁盘，也不自动刷新或重发提交。

原始配置连接测试与已保存服务连接测试均调用 Go。当前支持的五种下载器全部已有原生检查，未知类型返回参数错误，不再转发整个配置到 Python 测试接口。

## 任务、提交和回执

分页查询 running/error/pending 离线任务，保留云端原始大小写 ID。重复 ID、重复页游标、未知状态及无效结构会拒绝整个结果，不返回貌似完整的部分列表。状态单独显示失败或排队，不捏造下载百分比、速度、暂停和删除能力；没有暴露完整云端原始任务或私有下载地址。

磁力提交使用 NAS Tools 已有权限、按 hash 的跨进程锁及持久意图账本：发送之前登记 pending，真实响应包含合法云端任务 ID 后才能保存历史、事件和 submitted 回执。云端任务 ID 不是 torrent hash，保持大小写，不用 hash 冒充 ID。重启后相同请求返回原回执，不再次发送。登录阶段失败时尚未调用提交接口，可标记 rejected 并保留审计，允许用户排查后明确发起新请求；客户端不自动重试。真正提交之后的断线、超时、认证/验证挑战失败、无效响应或本地落账失败均保留不确定状态，不能自动重发。PikPak 的按 hash 正向核对仍未实现，待核查记录不会因列表暂时为空而自动解除。

支持默认云端下载目录，或已有目录规则中准确选择的 PikPak parent folder ID；不是 NAS 路径，不创建文件夹。不支持的标签、限速、暂停、做种要求及上传 torrent 文件会在提交前拒绝。搜索/订阅/RSS 的公共提交入口使用同一原生客户端和原有预约机制，PT 来源准入检查不被绕过；不代表云盘具有 PT 做种能力，也不代表本模块补齐各流程原本尚未完成的恢复能力。手动磁力是本批端到端回执回归重点。

## 剩余边界

未实现云端任务控制、云端文件转移、交互验证 UI、令牌持久化及按 hash 的不确定提交正向核对；不以删除旧源码或移除提示掩盖这些限制。其余插件/搜索回退、生产镜像 Python 依赖和旧实现最终清理仍需继续。整体迁移暂保持粗估 50–60%，功能覆盖和真实运行验收比文件数量更重要。

## 集中验证（2026-10-16）

后端 `go test ./...` 全量通过（HTTP 集成包 77.161 秒），`go vet ./...` 与 Linux amd64 无 CGO 静态构建通过。PikPak/downloaderconfig 竞态检测及 HTTP PikPak、原始下载器检查、手动下种、订阅执行/核查与订阅 RSS 相关竞态用例通过（HTTP 33.485 秒）。用例覆盖固定请求范围、凭据保护、代理 CONNECT 内存模拟、验证挑战拒绝、分页异常、提交不重放、大小写任务 ID、重启回执及登录前失败的审计保留。

前端 128 项测试、TypeScript 和生产构建通过；原有主包 530.80 kB 的非阻断拆包警告仍在。测试全部使用模拟网络、内存代理连接和临时数据库，没有连接真实账户、修改 NAS 文件或部署生产镜像。

退出检查仍为 migration in progress：360 个 Python 源文件、12 处 Go legacy endpoint 调用计数（本批从 13 降至 12）、75 处 legacy proxy/runtime 引用、45 处容器 Python runtime 引用。不能把原生客户端测试通过等同于 Python 已退出。
