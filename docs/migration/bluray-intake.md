# 蓝光整盘入库（2026-10-20）

本批将蓝光目录接入 Go 原生本地整理任务，不把 `BDMV/STREAM/*.m2ts` 当成多部影片。复制、硬链接、软链接和移动均按整盘保留目录结构、菜单、播放列表、证书、隐藏附属文件和空目录，使用一个已核验的媒体身份及一条兼容转移历史。不是 Python 完全退出或生产切换的完成声明。

## 范围与审核

结构识别要求 `BDMV/index.bdmv`、`BDMV/STREAM` 和至少一个 `.m2ts`，只证明可处理的目录布局，不证明蓝光二进制内容有效、光盘可播放或已下载完整。多卷集合仅合并 `Disc1`／`Disk2`／`BD1`／`CD1` 等编号卷，避免把共享下载目录中的不同影片合并。单盘最多 20,000 个节点、64 层，拒绝内部符号链接、特殊节点、Go 私有暂存名及已知未完成后缀。

选择整盘可直接预览；选择内部文件／子目录时须以 `allowDiscExpansion:true` 明确允许扩大只读审核范围。React 展示实际整盘源、目标、文件／目录数及总大小；保存和执行仍为独立操作。完整逐节点清单随私有任务定义参与指纹，新增或替换任一文件都要求重新审核，不由客户端提供或扩大。内部文件对应的旧未识别记录不能借此标记整盘成功，应另建整盘手动任务；原记录保留。

目录命名使用原模板的目录部分，不改 STREAM 内部名字。电影按整盘目录名识别；TV／动漫可明确指定真实季号而不猜集号，仍核验 TMDB 季信息。大小门槛按整盘累计字节计算，所有原文件分别要求至少 30 秒未修改。配置根本身是整盘时允许复制／链接，但不允许移动配置根。

## 写入与恢复

每个任务使用独占私有暂存目录，先建立完整空目录／文件及逐文件见证，保存 `staging` 意图，再写复制字节。每个原文件有固定身份及 SHA-256；复制保留原文件权限和修改时间，新建目的祖先目录逐级同步，完整核验后保存 `prepared`，最后以防覆盖原子目录改名发布。硬链接只创建硬链接，软链接逐文件指向已审核原路径，跨盘／文件系统不支持时不静默改成复制。目标路径按物理根及大小写／Unicode 归一的整棵子树预留，同时阻止父、子目标任务相互穿插。

中断不自动重扫或重复制。明确“继续发布”只使用原有完整暂存及见证；只读核对不搬文件。缺失、被替换、外来或额外节点保留待审核，不能用相同字节或“目标已存在”接管对象。首次意图提交前的崩溃仍可能留下无凭证暂存，继续保留，不自动删除。

移动先发布独立完整副本，另行确认源移除后保存源恢复意图，再将原整盘目录原子转入其父目录下的私有恢复目录。完整源捕获后才提交历史；两阶段清理回执逐一完成，之后才派发业务事件。清理只移除凭证中的原节点，新到的同名源目录及额外文件不删除。源清理后的空私有目录保留至“源已清理”回执提交，避免从源路径缺失推定成功。

明确放弃未发布暂存要求独立删除确认、实际停止旧执行器和原源完整证明。完整副本需逐文件原 SHA，半写副本需逐文件原前缀；整任务先提交放弃意图，清理只容忍该意图后缺失的已知节点，不清理未知对象、不写成功历史，最终回执完成才释放子树预留。检查按逐文件字节线性执行，不在每次删除时重读整盘。操作最长两小时并保持取消传递；超时／断线不表示可以自动重发。

## 原生联动

下载完成整理根据下载器明确选中的完整文件清单核对整盘，隐藏附属文件也须逐项在清单中；未选中／未广告的邻近文件导致整盘拒绝，不拆片执行。qBittorrent、Transmission 和 Aria2 沿用原批次、移动停种授权、结果回写授权和持久回执，不因整盘入库自动改标签或删任务。

识别同步监控以整盘为一个稳定候选，摘要覆盖目录内的路径、身份、大小和修改时间；内部变化使候选失效，自己的硬链接计数变动不制造新到达事件。忽略规则命中任一内部节点时过滤整盘，不生成残缺光盘。

完整任务及移动清理完成后，入库刮削在电影整盘根写 NFO／图片，TV 在季目录写 `season.nfo`、在节目目录写节目 NFO／图片；已有文件不覆盖。无片段到剧集的核实映射时，TV 逐集 NFO／缩略图明确略过并记录 partial，不猜主片、不解码任意片段。ChineseSubFinder 回执保持真实整盘目录身份，按旧协议派生 `目录/目录名.mp4` 虚拟路径及 `is_bluray:true`，不是创建 MP4；原任务、配置代次和目录凭证重新核验后仅提交一次。

## 验证与剩余范围

回归覆盖临时真实文件／SQLite／模拟接口中的四模式发布、目录历史、全范围未知记录、元数据／字幕顺序、下载器完整清单、识别同步监控、多卷、隐藏附件、空目录、共享原 inode、冲突、替换、半写、显式续发／放弃及移动后新同名目录保留。完整实现后集中运行后端全量、相关竞态、静态检查、Linux 无 CGO 构建及前端测试／类型检查／构建，不对真实 NAS 或真实下载器写入。

最终验证通过：后端全量测试（HTTP 102.220 秒、整理内核 10.707 秒）、相关竞态检查（HTTP 103.111 秒）、`go vet ./...`、Linux amd64 无 CGO 静态构建、前端 150 项测试／类型检查／构建。前端主包仍有既有的 500 kB 体积警告；未用此构建结果替代浏览器、容器或真实大盘性能验收。

已有媒体库的蓝光批量强制重刮仍待独立迁移，当前明确阻止将 STREAM 片段当作独立媒体；本批覆盖的是入库后的整盘刮削。远程整理、无凭证／未知恢复对象的人工处置、其余保留业务以及真实 NAS、大盘性能、浏览器和 Go-only 镜像启动验收仍未完成。当前 Docker daemon 不可用，未据此启动生产或提前删除旧 Python。
