# 下载任务联动删除（TorrentRemover）

2026-11-06 已接通原插件配置、安装生命周期、真实 Go 源文件删除事务、持久队列、下载器执行和 React 管理入口。原 Python 随全域退出再删除；本模块的 Go 实现和隔离验收不代表全项目已退出 Python。

## 原配置和未来事件

沿用 `plugin.TorrentRemover.enable`，保存时保留未知 JSON 字段和大整数，同时撤销原后台授权。React 在安装后显示原接收方的名称、协议和主机，当前主管理员须分别确认范围、保留文件，以及已停止旧执行器和其他任务写入器，才可启用未来事件。下载器 API 无法原子锁定外部任务修改，因此启用范围内需停止其他会移除、重建或改动这些任务的执行器。

旧启用开关、普通读取或 Go 重启均不会自动授权。混合运行模式只读；安装、保存、启用、停止和核对只在 Go 独立模式执行。配置编辑、停用和卸载关闭后续工作。原插件的配置／状态／页面和安装路由均由 Go 接管，受保护的原始配置入口不能绕过该路径。

只在 `organization` 的源文件删除子事务已核实完成后，从其原事件及原历史建立候选，并与业务事件同事务持久化。一般 Webhook、历史事件列表及任意路径请求不能制造联动删除任务。没有媒体身份或可用历史的事实不会扩大删除范围；原关联历史损坏或范围不完整时留作阻止记录，不移除任何子集。

## 原关系与任务核对

原 `DOWNLOAD_HISTORY` 按标题查候选，再读取精确下载器／任务编号、原保存目录、创建记录、`TorrentTransfer` 和 `IYUUAutoSeed` 关系。保留原转种时是否删除源任务的关系，以及原插件只联动同下载器辅种的边界。相对文件名按完整路径组件匹配，不接受越界或部分名称碰撞；辅种必须等待原父任务已确认移除。

当前远端保存目录须匹配原下载历史；转种目录按照冻结的原 frompath／topath 配置转换。qBittorrent／Transmission 额外读取加入时间，要求不晚于对应下载、转种或辅种历史的创建时刻，并在写入前再次核对同一实例。缺少原目录或有效创建时间时阻止自动移除。历史行、原转种设置、当前管理员及下载器完整配置也会在请求前复核。

复用 Go 已有 qBittorrent、两代 Transmission RPC 和 Aria2 客户端，以及现有 PT／做种、配置与任务锁。qBittorrent 的 `deleteFiles=false`、Transmission 的 `delete-local-data=false`／`delete_local_data=false` 明确保留全部文件；Aria2 仅移除已完成结果，不调用文件删除。任务标签不作为解除 PT 义务的依据。

## 意图、防重、停止与历史

每个源事件都有稳定回执，各关联任务独立保存状态。远端移除之前，事务登记下载器／任务／实例的跨事件占用和写入意图；同一实例不会因为另一个源文件事件、另一条历史或另一个角色而重发。应答丢失、中断和未知意图不能回到待发送状态。进程恢复仅在持有跨进程执行锁后关闭旧运行状态，不接管其原请求。

停止阻止后续请求，已发出的请求仍需读取原下载器确认。只读核对要求当前主管理员重新审核当前范围，并保持原下载器配置完整匹配；关闭插件的开关不会让未知回执失去只读入口。它只读取任务是否仍存在，不重新发送移除。原授权已停止或关系已变化时，可记录已观察的任务结果，但保留旧关联历史。

只有对应任务已确认移除，且原设置、下载历史和完整关联快照仍匹配，才事务删除原转种关系、更新本下载器的已移除辅种项。其他下载器、未确认项、未知 JSON、大整数和原日期保留；不删除 `DOWNLOAD_HISTORY`。没有确认完成的关系不会被当作清理成功。

React 提供范围审核、启用、停止、只读刷新、逐事件／逐任务记录和未知结果核对。保存配置会撤销原授权。当前没有把真实浏览器操作写作已验收。

## 集中验证

先接通整个模块，再统一运行行为测试。最终相关 Go 竞态 135 项、下载器三包完整竞态 187 项、前端 358 项均通过，无失败或跳过；Go 静态检查、本机及 Linux amd64 无 CGO 构建、前端类型检查和生产构建均实际退出 0。本批没有重跑 Go 整库测试。

验证覆盖精确大编号、原转种与同下载器辅种、条件历史更新、父任务条件、配置撤销、任务实例变化、未知响应、跨源事件防重、关闭插件后的只读核对、真实 Go 源删除事务，以及本地、模拟 MinIO 和本机临时 Rclone 别名的删除回归。下载整理用例同时验证共用任务锁未破坏原行为。

独立审查发现跨事件未知意图可重发、原历史未绑定当前任务实例，以及关闭开关后不能只读核对三个问题。分别用失败用例复现，补齐持久实例占用、保存目录／加入时间核验及独立只读范围后通过。首次协议夹具遗漏 Transmission 文件统计字段和 Aria2 凭据，已按实际协议补齐；失败轮未计入通过。首次扩大回归因本机监听权限导致 MinIO 测试中断，获准使用本机模拟端口后相同范围完整通过，没有跳过远程分支。已有前端主包大于 500 kB 的构建提示仍在。
