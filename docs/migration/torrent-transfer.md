# 自动转移做种（TorrentTransfer）实施状态

目标为保留原 TorrentTransfer 的下载器选择、排除标签／目录、路径转换、源种子文件与 qBittorrent fastresume Tracker 补充、暂停添加、校验、可选启动、保留文件的源任务移除、原转种历史、一次／周期和通知，并接入 Go 持久回执与 React。

2026-11-06 第一阶段已新增独立核心，尚未接入生产调用者：

- `torrentmeta.PrepareTransfer` 复用现有完整文件清单解析，只修复外层缺失的 Tracker 字段，优先沿用种子自己的 announce-list，再读取匹配原 info 的 fastresume；原始 info 字节不重新编码。未知外层字段原样保留，已存在的 announce 不用另一个 resume 改写。公共无 Tracker 种子保留 DHT 行为，私有种子缺少原 Tracker 证据时不猜测接收方。
- `torrenttransfer` 读取原设置并保留未知 JSON 与大整数，源／目标编号不经浮点数。保留原排除语义（qB 标签包含匹配、Transmission 完整标签、目录前缀）；目录映射按完整组件；远端目录格式支持 POSIX、盘符和 UNC，阻止越界与文字前缀相撞。
- 元数据目录使用只读根句柄，绑定规范路径及文件系统身份；只读内容与源任务完整哈希匹配的 `.torrent`。可显式使用原协议给出的种子文件名，但不能借此读取其他文件类型。读取前后复核目录、文件类型、身份、长度、时间和内容摘要；拒绝源文件符号链接、根目录替换和原别名重定向。
- Tracker URI 和原始种子内容只留在私有内存字段，不进入普通 JSON 进度。没有写回原种子、创建替代种子文件或操作媒体文件。

已编写覆盖 info 字节与哈希、v1／v2／混合元数据、私有字段不进入进度、已有 Tracker、错误 resume、公网 DHT、精确编号、旧目录前缀／两类标签过滤、只读与复核、路径逃逸／符号链接／根替换／取消的回归夹具。遵照用户要求，行为用例待整个模块调用链完成后集中运行；本阶段仅进行编译和静态检查，不能据此声称这些行为用例通过。

后续仍需接入源／目标协议、下载器版本和 v2 任务标识核验、暂停添加、校验／启动、源任务保留文件移除、跨周期动作账本、PT 与范围保护、原历史／通知，以及 React 审核、停止和未知结果查询。可解析 v2 元数据不表示任意目标下载器支持 v2；缩短的 v2 任务标识也不能未经协议核对就当作完整哈希。

本阶段没有启用新后台、发送种子或启动／移除任务，原 Python 插件仍保留。完整计划见 [实施计划](../superpowers/plans/2026-11-06-torrent-transfer.md)。
