# 自动备份

Go 独立运行模式接管 AutoBackup 的安装、原配置、手动执行、一次运行、周期、停止和执行记录。React 在插件页提供管理入口，服务页可创建并下载原格式的精简备份。`POST /backup` 使用当前主管理员的 Go 登录令牌。原 Flask 会话脚本需要切换到 React 入口。

ZIP 保留 `config.yaml`、`default-category.yaml` 和 `user.db` 三个原文件名。SQLite 在线备份读取已提交的 WAL 数据并保留隐式行号。精简模式仅在快照中删除旧版指定的九张表。容器继续使用配置目录下的 `backup_file`。本机自定义目录的上一级需存在，归档目录由服务账户拥有且禁止其他账户写入。

周期和一次运行需在 Go 界面确认，设置变更会撤销旧授权。发布前登记文件指纹，归档以私有权限写入并避免覆盖。重启可核验已经发布的归档并查回记录。保留数量只应用于有 Go 执行记录且通过指纹核验的自动备份。如果计划保留的归档缺失或损坏，本次跳过清理。旧 Python 归档及服务页的手动导出可独立管理。清理前登记意图，重启只核对原文件是否已移除。

117 项相关 Go 竞态测试和 353 项前端测试通过，另有 1 项既有 rclone 测试跳过。Go 静态检查、前端构建及本机和 Linux 的无 CGO 构建通过。隔离 Go 进程验证了原格式下载、匿名拒绝、一次运行和重启回查。浏览器控制超时，React 点击流程仍待验收。真实备份挂载及生产镜像继续验收。恢复流程另见 [配置和数据库离线恢复](backup-restore.md)。
