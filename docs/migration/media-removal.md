# 历史、来源和已发布媒体的独立删除

2026-10-23 后续：旧目标及不确定范围的释放由 [独立预留释放](reservation-release.md) 接管；本页删除操作仍不附带释放授权，以下集中验证保留本模块原批次证据。

本模块将旧 `delete_history` 的记录、来源／媒体库选择及精确黑名单／同步去重清理接入 Go；直接文件选择接入同一流程。不是恢复副本清理的别名，也不把未知当前文件当作原整理凭证。管理员先只读审核完整范围，再保存稳定批次，另行新审核并明确执行一次；没有后台删除 worker、启动重放或自动错误重试。

## 范围与兼容

- 历史编号用十进制字符串传递，支持 SQLite 正 int64 范围，不经过 JavaScript 浮点数。批次最多 100 条历史、1,024 个独立对象范围；整个批次最多 20,000 个目录／文件／链接，总载荷上限沿用 1 PiB，累计前检查溢出。完整读取仍受两小时操作预算限制，数值边界不代表真实大盘吞吐已验收。
- 保留“只删历史”“同时删来源”“同时删媒体库”“两边都删”。所选历史的全部 SQLite 原始列和值随批次留档，保留 NULL、空文本、整数、实数、BLOB 和额外列；公开摘要不携带这些完整私有行。
- 精确读取所选原来源的 `TRANSFER_BLACKLIST` 和 `SYNC_HISTORY` 行，显示影响数量。不清空全表，不改未选择的其他历史。它们与历史行在最终事务中一并删除，原始内容有任何变化则拒绝最终提交。
- 原始行留档的 64 MiB 预算按整批累计，不把每个历史编号都当作新的预算；完整持久定义也最多 64 MiB。文件清单合并包含关系后，同样按整个批次检查对象数与载荷预算，超限整体拒绝，不保存截断工作清单。
- 历史有精确源／目标名时优先使用它们。缺少精确目标的旧聚合记录按当前旧命名模板生成完整电影／季目录；有明确集数时，只选择同季且集数完全属于所选范围的文件，不能拆删跨越范围的多集合并文件。无法无歧义解析时须由管理员明确选择实际配置内路径，不借缺失字段猜另一个目录。
- React 可浏览已配置来源／媒体库并选文件、完整目录或蓝光载荷，也能为某条历史明确补充旧布局。历史中的任意绝对路径不授予越出当前配置根的权限；远程明确选择 Rclone／MinIO 原账户，不能降级到同名本地目录。
- 同名 NFO 和目录清理分别选择。目录清理只提出直接父目录、季／媒体目录的候选；只有扣除本次明确范围后没有其他媒体，才把**当前整个目录**及全部其他成员纳入新审核。不能选择配置根；样例最多 100 项，不是只审核样例或只删除成功子集。

旧 REST `POST /api/v1/organization/history/delete` 的无 flag 请求仍是记录专用通道，不查账户、不删除文件，存在待关闭的关联任务时须改走完整审核。文件 flag 使用 `/history/delete/plan` 与明确授权，保存后返回稳定批次，不伪装为文件已删除。`/organization/files/delete/plan`、`/organization/files/delete` 可将旧绝对文件列表转换成同一原生批次，也要求完整审核和独立授权；不会继续调用旧 WebAction 或开放任意路径。旧 Python Ajax 页面与插件消费者尚未因此完成生产切换。

## 持久执行与事件

1. 根、账户／执行环境／信任配置、完整内容 SHA-256、本机节点／链接字面值、原历史／去重行、操作者、原因与全部关联任务共同绑定审核。
2. 同一事务保存批次和每个完整对象的子工作清单，状态为 `ready`。保存不关闭旧任务、不删除文件或历史。
3. 新审核整个剩余批次，独立确认历史删除、去重重置、永久／唯一副本风险、附件／完整目录范围、停止全部外部写入器、关闭关联任务及远程独占。勾选不会代为停止 Python、其他实例或下载器。
4. 复用整理、入库补充、媒体库发布、远程命名空间及全部关联任务的跨进程锁。首个意图与整批关联任务关闭同事务；旧多库批次必须关闭全部兄弟任务。新整理和刮削任务的保存还检查未完成／已停止删除批次的范围占用，不能绕路写回正在处置的媒体。
5. 本机按完整对象先防覆盖捕获，再按已审核清单逐叶存意图、核验和删除；只删本机符号链接本身，不跟随链接。目录仅空时移除，不对新发现的内容递归删除。Linux 须正向证明挂载 ID，Darwin 检查设备边界。
6. 远程复用精确单对象删除能力，只有完整内容和清单核验通过才单次删除；不清桶、不批量扫前缀、不强制清版本或绕过保留策略。不宣称跨服务商原子比较删除，未知未完成分片上传不列举／中止，也不保证物理容量立即回收。
7. 每个实际存在的来源／媒体库选择完成后，其逐项回执与结构化 `source_file_deleted`／`library_file_deleted` 事件同事务保存。事件含实际选择路径、原媒体摘要和稳定批次／历史编号；重启或重复核验不再发一次。原本不存在的对象及没有历史归属的直接文件选择不伪造这些事件。事件可在原生业务回执中查看；记录事件不启动 Python 插件或自动删除下载器任务。
8. 全部选择已核验不在原位置后，才在最终事务删除精确历史／去重行并提交 `completed`。部分文件已删而最终数据库失败时，原行完整保留，批次须新审核；不能为补数据库回执重发文件删除。

网络失败、取消、回执丢失或重启都停止本轮。后续明确新审核才可继续；有持久删除意图的确切缺失仅补回执。新对象到达、内容变化、根／账户配置撤销均阻止旧范围继续。重复已用审核键只返回现有批次，不访问原存储或重发删除。

React 在发送保存请求前保留已知稳定编号，错误清空授权但不丢这个编号；较早或不在最近 30 条列表中的批次也能输入编号只读核验，不为找回回执重复提交删除。

整批停止不等待工作锁或长读取，取消后续工作；已送出的单次删除可能仍完成。尚未删成员的本机捕获可另行新审核、防覆盖归还到原空位置，随后整批停止；不重开旧任务，不覆盖迟到对象，也不能恢复已删兄弟范围。已停止／完成批次可不依赖已撤销账户只读查看。

## 集中验证

整模块实现、React 流程和临时夹具用例编写完成后统一运行。最终不缓存后端全量通过：32 个含测试包、2,593 个测试／子测试通过事件，HTTP 包 1,406.788 秒；另 5 个包没有测试文件。唯一跳过的是仅供子进程调用的 `TestJobGuardSubprocess`，真实 Rclone CLI 用例未跳过。整模块针对性回归 60 个通过事件；相关 HTTP 竞态 144 个通过事件、219.294 秒；整理／远程存储／事件整包竞态分别 129.234／20.018／1.858 秒，均不使用测试结果缓存。上述结果均已取得完成退出码 0，不把运行中的部分结果视为全部通过。

静态检查、Linux 无 CGO 静态构建、模块缓存校验通过；359 项生产依赖不含测试夹具或测试 HTTP 服务。前端 221 项测试、类型检查和构建通过，无失败或跳过；633.89 kB 主包的现有 500 kB 警告保持，没有调高阈值。

覆盖三种存储的完整历史／来源／媒体库／附件批次、原始 NULL／int64／BLOB／额外列、准确去重行和最终事务回滚、完整目录／整盘及本机链接、旧聚合历史的实际命名／集数、目录清理不吸收其他集、缺失／迟到内容、完整旧多库任务关闭与预留保持、禁止新写入和私有子任务旁路、删除响应丢失／重启不重放、逐项完成与事件同事务、停止取消在途读取、防覆盖归还、权限／配置变化，以及整个批次的对象／字节／原始行预算。数值上限只作整数运算和拒绝路径验证，不宣称已处理相应规模的真实媒体。

隔离本机浏览器使用本次构建的 React 和 `NASTOOL_DISABLE_LEGACY=true` 的 Go 服务、临时配置与临时数据库，验证登录、只读审核、仅保存不删除、重新审核后授权单次执行、完成回执，以及刷新后输入稳定编号只读找回。永久删除前取得用户对 `/private/tmp/nastool-media-removal-browser.cTqSS3/library/delete-me.txt` 的具体授权；实际只删除该 57 字节夹具，未选 `keep.txt` 的 68 字节内容保持不变，临时媒体目录只剩 `keep.txt`。保存前／完成后的截图留在该临时根目录，服务与测试标签已关闭；没有操作用户媒体、现有配置、数据库或服务。

测试仅使用临时本机目录、空账户环境的隔离 Rclone 别名和虚构账户／临时 CA 的内存 S3 服务。上述浏览器证据仅覆盖单个本机临时文件，不代表远程浏览器流程、真实 NAS／云账户、跨挂载或实际生产镜像已验收。Docker 由用户自行启动，不由代理启动或操作已有容器。

## 仍在整体目标内

旧整理目标／不确定占用不因删除文件或历史自动释放；后续已由独立、留痕的 [预留释放](reservation-release.md) 流程接管，不共用删除授权。删除事件的其余原生插件消费者、下载器／转种联动及 PT 安全策略、其他保留业务、存量大账本分页／索引化和生产切换继续保留在目标内。本模块不据此删除 Python、清理用户下载任务，或宣布整个整理领域／Python 退出完成。
