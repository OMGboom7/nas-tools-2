# Cloudflare IP 优选迁移

2026-11-02，基线 `64d84e2`。本模块按原 `app/plugins/modules/cloudflarespeedtest.py` 的完整范围迁移，继续使用 XIU2 的 Go 测速程序；由 Go 服务负责安装、配置、执行、结果核对、Hosts 更新、周期和通知，不启动 Python。

保留原 `cf_ip`、五段 `cron`、`onlyonce`、IPv4／IPv6、`check`、`re_install`、`additional_args`、`notify` 与版本字段。原插件 JSON、Hosts 的字符串／列表格式及未知字段保留；IP 校准只在出现次数最多的有效地址唯一时生效。测速结果只替换第一列地址等于原目标 IP 的映射，注释和其他映射保留。

原实现已经采用 Go CLI。继续使用它能保留高级测速参数；重新编写测速算法会改变排序和参数语义，继续调用旧插件不满足 Python 退出目标。安装从官方发布清单识别 `CloudflareST`／`cfst` 新旧资产，支持 Linux／macOS 的受支持架构；保留可用本地安装的离线回退。重装使用独立目录和原子发布，不删除整个旧插件目录。两种地址族合并成一次输入，避免两个 `-f` 参数互相覆盖。命令使用参数数组执行，不使用 shell。

完整集成需要管理员核对并接管原配置；旧开关不在启动时自行取得运行权。未来周期、单次运行及允许签到触发分别保存，使用跨进程任务锁。执行前持久保存原配置／Hosts、版本及动作意图，未知执行和重启不自动重发；文件与数据库无法一次提交，需保存写入意图和完整前后快照，并支持只读核对实际结果。成功后才更新 `cf_ip`／版本和原 Hosts 配置，并向原通知消费者提交一次完成通知。

签到达到原 `auto_cf` 阈值时，在优选接管仍有效且允许该入口的条件下，按原签到批次编号排入一次优选；没有授权、配置变化或未知结果均保留明确状态。优选独立历史、启停和 React 管理入口属于本模块范围，不能用后端工具包代替完整迁移。

集中验收在整个模块接通后执行：新旧资产安装／离线回退／归档边界、真实 Go 临时测速程序、双地址族及高级参数、CSV 结果和旧文件隔离、原 JSON／Hosts／大整数保留、周期与单次时间、签到触发、通知、跨进程／中断／只读核对、React 临时页面及平台构建。实现中只做必要编译检查，不为每个小修改重复测试。真实公网测速、系统 Hosts 与真实账号不作为临时数据验收对象。
