# 精确订阅洗版轮次

2026-10-26：精确订阅的质量轮次、真实接收记账、明确封存和原配置恢复已接入 Go／React，并完成本模块集中验收。不将本批视为完整高级订阅／Python 退出完成。

## 保留与纠正的业务语义

精确洗版核验 TMDB 身份，不使用已有媒体库存作为完成条件；资源只在规则优先级高于 FILTER_ORDER 时接受。电影一次接收完成一个质量轮次，未达到组最高优先级时保留规则。电视剧一个轮次固定过滤组、质量优先级及指定起始集到总集数的目标，只有全部目标已获得接收事实才推进优先级；不同质量的部分集不能拼成一份完整高质量结果。普通 RSS_TV_EPISODES／TOTAL／LACK 记录独立保留，不将旧库存／缺集进度当作新洗版完成。此处故意纠正旧搜索对部分剧集接收就推进整体质量、RSS 又忽略带集资源推进的不一致，既有配置和旧字段保留。

洗版仍不等于下载或整理完成。当前洗版规划只接收声明季集全部落在本轮剩余目标内的资源；尚未核验种子的完整文件清单，不能将标题匹配称为逐文件核验。跨季包、需要拆选文件的整季／重叠资源尚未开放，不以“规划中取交集”授权下载整个包。原生基础订阅目前也缺少完整文件选择：普通规划的缺集交集不等于下载器只下载交集。先补实际文件清单和选择，再补跨季协调，不能据此宣称高级订阅全量迁移。

## 完整链路

- 管理员搜索／立即搜索、R/D 周期搜索及 RSS 共用规划、共享提交预留和实际下载器。已有模糊订阅保留独立授权批次，不偷换为精确洗版。
- 新质量轮次与首个提交意图同事务。范围绑定完整原行、实际季集、过滤／词表／站点／下载器／设置及识别配置。活跃轮次不会因更高质量出现、重启或超时自动更换；配置变化阻止沿用旧结果。
- 每次提交私有证据采用独立版本，包含原轮次与精确质量；旧普通核实和模糊批次不错误采用另一类语义。逐项接收、原 URL 共享记账、下载事件、轮次剩余及优先级推进同事务。未知提交保持预留，正向核实不重发、不虚构已完成集。
- 明确的认证／配置拒绝才释放原预留，但保留独立尝试记录。已接收、拒绝、待核实意图均保留；稳定轮次编号可在来源收尾后只读查回。
- 完成记录保存完整原行及 TV 辅助账本，INTEGER 精度／REAL／NULL／BLOB 保留。历史重新订阅恢复原洗版、过滤、目录和此前优先级，不重新猜 TMDB 或采用新的默认订阅设置；稳定请求不重复创建，原历史及旧接收事实保留。
- 现代／旧表单编辑和删除封存活跃质量轮次。明确编辑洗版规则重置此前优先级，界面说明此行为；不清除原未知预留。独立封存要求本地新审核、完整轮次指纹、明确确认和原因，未知提交禁止借封存绕过；不删除或撤回下载。既有周期后续可以新建完整质量轮次，费用与范围在确认中明示。
- React 区分普通进度和质量轮次，展示完整目标／剩余、逐项接收事实及最高优先级。来源页刷新、错误及会话切换不重发，封存前保留稳定编号。

## 原生接口

`GET /api/v1/subscriptions/{MOV|TV}/{id}/upgrade` 只读当前源及原活跃轮次。`POST .../upgrade/reset` 只封存本轮，不立即执行新下载。`GET /api/v1/subscription-editions` 返回最近 30 条原生质量轮次，`GET /api/v1/subscription-editions/{cycleId}` 按稳定编号返回完整接收／拒绝／未知尝试，最多 1000 条，超限不截断冒充完整。所有入口要求当前管理员与纯 Go 模式；未知方法／子路径在本命名空间内明确拒绝，不回退 Python。
