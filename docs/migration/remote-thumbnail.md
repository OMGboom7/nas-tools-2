# 远程入库 FFmpeg 缺图回退

范围：Rclone／MinIO 原生入库已完整成功的普通剧集视频，沿用原 `episode_thumb`／`episode_thumb_ffmpeg` 开关和第 181 秒。只有权威集图字段确实缺失才进入回退；无效图片地址不是解码授权。已有图片保留，蓝光不猜选内部 STREAM 片段。本批不是远程已有库遍历／强制覆盖刮削的完成声明。

## 读取与内容凭证

原任务必须完整完成，普通媒体的持久远程凭证、账户、配置与独占范围授权仍有效。Go 完整读取最终对象并核对保存的 SHA-256，在内存建立 4 MiB 分块摘要；每次范围读取先取完整块并核对摘要，再把需要的字节交给解码器。对象路径、列举元数据和账户也须保持一致；结束后再次核验完整最终对象，才允许沿用原侧车发布流程。ETag、文件大小或修改时间都不能代替内容凭证。

不把逻辑云路径当本机文件，不提供预签名 URL，不通过非可定位管道冒充完整支持，也不落盘缓存第二份视频。索引上限 1 TiB／8 MiB 摘要；单次解码限 90 秒、512 MiB 实际分块读取和 256 次分块请求。超限留下失败回执，不静默截断为成功；完整核验本身仍有原存储协议的读取时限，会产生额外云端读取流量和费用。

Rclone 使用既有冻结配置与隔离环境的 `cat --offset --count`，只接受非负范围和精确字节数；MinIO 使用原生 Go SDK 单次 Range GET，须返回准确 Content-Range 与长度。忽略范围、错位、短读和同尺寸内容变化均拒绝。读取能力在回调结束即关闭，不能以新上下文继续访问。

## 解码与队列

仅为一次解码建立 `127.0.0.1` 临时读取桥，随机 256 位路径令牌，严格匹配主机／路径／GET 或 HEAD，不代理任意对象、请求参数或外部地址。支持单段、开放结尾和后缀字节范围，不接受多段／溢出。端口、子进程和正在进行的读取在结束／取消时全部回收。

FFmpeg 只得到上述临时地址，无账户、原云端地址和用户命令模板；环境不继承代理或报告配置。协议限 http／tcp／pipe，解复用格式限既有容器清单，禁止播放列表／concat 与本地文件协议，MOV 外部数据引用明确关闭。仍复用单帧 JPEG 输出校验、8 MiB 输出上限及进程组终止。读取桥不是对解码器漏洞或被替换执行文件的操作系统沙箱。

持久刮削声明先于解码；配置／账户撤销在逐请求及一秒监测中检查，并中断在途操作。失败、过短、缺少工具、超限、取消及发布回执丢失不自动重跑。元数据发布仍先记录意图、核验媒体、不覆盖已有对象；不确定回执保留原文件和暂存，未增加自动恢复／删除操作。字幕提交继续等待本轮刮削终结，不重复整理或转移历史。React 显示读取费用／上限和原失败回执，不提供隐式重试。

## 集中验收

代码与回归整体完成并修正首轮问题后统一验收通过：不缓存后端全量（HTTP 1178.219 秒）、不缓存相关 HTTP 竞态（136.381 秒）、不缓存整理／远程存储／解码竞态（100.205／19.397／9.454 秒）、静态检查、Linux amd64 无 CGO 静态构建及模块缓存校验。生产依赖清单确认测试服务和虚构账户不进入程序。前端 198 项测试、类型检查及构建通过，主包 591.62 kB（gzip 162.99 kB），保留原 500 kB 分包提醒。

测试使用真实隔离 Rclone CLI、虚构账户／临时 CA 的内存 S3 服务和真实 FFmpeg 合成视频。两种 provider 的真实 MKV、尾部 moov MP4 均经原任务内容凭证发布 JPEG，字幕在后，重启不重跑。覆盖四种字面方式、已有图片保留、错误／缺少 FFmpeg／短视频、范围忽略／错位／短读／篡改、完整摘要错误、分块边界、读取预算、账户／配置撤销、取消、发布回执丢失及播放列表不访问引用资源。

回归发现并修正两类真实解码问题：MOV 私有选项不能无条件用于 MKV；可定位 MP4 会先打开新请求、再关闭旧流，读取桥须允许两个有界在途流并同步共享预算，避免旧流阻塞尾部索引跳转。前端测试加载同时保持现有 Node 18 兼容，未提高运行版本要求或跳过失败用例。

这些测试不使用真实云账户、NAS 或生产视频，不能替代真实对象服务吞吐、浏览器或 Go-only 容器验收。用户选择稍后自行启动 Docker，不由代理启动 Docker Desktop。远程已有库三模式刮削、未知无凭证对象和保留副本的独立处置、其余保留业务及最终生产 Python 退出仍待继续。
