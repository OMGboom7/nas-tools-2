# 精确 TV 订阅的跨季协调

2026-10-27：普通精确 TV 订阅及精确洗版可将同一跨季资源的一次实际文件选择，联合登记到原来各季的订阅。Go／React、持久阶段恢复、RSS 和周期搜索已接通。本模块不代表高级订阅、生产切换或 Python 退出全部完成。

## 一个下载任务，各季独立判断

例如原 S01 缺 2、3 集，原 S02 缺 1、2 集，S01–S02 包只包含这四集及其他文件。本流程只添加一个暂停任务，选择这四集及对应字幕，核验并启动一次，再联合提交两份原订阅的实际接收。已经存在的 S01E01、没有明确季号的根目录 E01 和程序等额外文件保持不下载。

每个成员必须是同一 TMDB 媒体的原精确 TV 订阅，具有有效 R／D 状态，并独立经过自己的原搜索或 RSS 来源、站点、过滤规则、库存／缺集或质量轮次规划。不能把首季可用的站点、匹配结果或下载设置借给其他季，也不为包内未订阅季创建订阅。下载器、目录和完整每任务设置必须相同；矛盾设置在添加前拒绝，而不是取首季默认值。

按实际种子文件的明确季号分别规划，各季最终选择取并集；跨季根目录不能把裸 E01 同时解释为多季。某成员没有实际覆盖时不计接收，原缺集保留；发起季必须有实际覆盖。不可拆多集文件继续要求其全部集属于该季目标。清单、hash、索引和路径的完整性约束复用 [实际文件选择模块](subscription-file-selection.md)，不因跨季放宽。

洗版每季保留自己的过滤组、质量优先级和完整目标。一次共同下载可以完成某季最高质量，使另一季只推进较低质量并保留订阅；不同质量不能拼成完整轮次，也不消费原普通缺集账本。模糊 RSS 继续使用独立关键词／季范围及整资源授权语义，不套用本批精确媒体的逐季缺集拆选。

候选季范围跨度小于 100，同媒体原来源查询超过 1,000 条或匹配成员超过 100 条时拒绝，不截断成“完整范围”。公开来源 ID 使用十进制字符串，避免前端大整数精度丢失。

## 冻结范围与共同事务

- 私有原来源证明 V5 保存有序、唯一的逐季 V4 叶证明及原候选季范围；叶证明绑定完整原行、原始 SQL 类型、辅助缺集账本、规则、配置及独立质量轮次，不允许递归嵌套或从不相干证明采用旧接收。
- 文件选择定义 V2 保存全部原订阅 ID、季号、总集数和实际选集。原 V1 单季定义及其指纹兼容保留。完整清单、下载器设置、全局配置和联合范围共同参与原指纹。
- 首次添加前的一个事务同时保存原文件定义、唯一共享资源占用、全部成员 pending 和各自质量尝试。`GO_SUBSCRIPTION_SEASON_MEMBERS` 保留 pending／submitted／rejected 事实；任一来源或同媒体同季仍有未知占用时，新入口不能绕过。
- 全部文件、原设置／PT 和所需启动取得正向回执后，原事务同时提交私有 committed、一个共享提交、一条 `RSS_TORRENTS`、一个 `download_start`、每季实际缺集／质量推进，以及需要收尾的各季原行、历史和 `rss_finished`。一个任务不虚构多份下载事件。
- 最终再次核对私有定义与指纹、完整成员、共享原证明、实际下载记录、所有保留源行及质量轮次、所有完成历史与封存。任一静默忽略、触发器篡改、成员变化或后来重建源行，使整个业务事务回滚；远端已成功动作保持原阶段，不重新添加或启动。

同媒体各季的后台任务串行处理，不同媒体仍最多四组并行。RSS／周期搜索只根据本次执行返回的逐季正向接收跳过已完成的已捕获兄弟任务；不因老 ID 或旧接收事实跳过新订阅。手动与跨进程并发仍由持久预留约束，调度分组不替代事务。

## 未知结果与原历史恢复

任一成员的旧核实入口都定位到同一个原任务；原文件选择的添加、设置、取消选择、选择、启动和仅登记阶段仍分别持久化，不确定动作不自动重放。核实前复查全部原成员，不能编辑首季或第二季后继续采用旧范围；最终仅登记复用同一联合事务。

React 展示全部冻结原订阅与完整原文件清单。每次新审核都重置确认，所有可执行恢复阶段额外要求确认“全部原季订阅”；通用确认不替代跨季范围确认，启动和登记也保留独立确认。后端 `confirmSeasons` 同时强制检查，前端拒绝采用响应中变化的来源集合。成功恢复清除已过时的父页面搜索失败提示，再重新读取原订阅。

普通文件流程使用独立 V2 原行历史封存，保存原 `FileSelectionID` 和完整类型／未知字段；原精确洗版 V1 封存仍要求洗版证明。跨季仅部分接收后，后续普通资源完成同一来源也保留这份恢复依据。追溯按 ID、媒体、季号共同匹配，不把复用 ID 的其他媒体旧任务当作新授权。

原配置重新订阅恢复原季、过滤、目录、普通账本及原始 INTEGER／REAL／NULL／BLOB 值，进入既有 D 搜索周期；恢复请求本身不请求上游、不重加旧任务、不重开旧范围。来源收尾后仍能按原稳定文件编号查回完整回执。
