# Go PT 限时管理员核实

旧 Python 实现只找到资源详情 HR 标记检测，没有可复用的站点账户义务解除验证。本模块不是自动 HR 验证器：管理员必须自行在站点账户逐项核实准确任务的 HR 及全部义务，再明确登记声明。后台不得把详情页无标记、搜索摘要、完成后的墙上时间或本地分享率当成账户解除证明。

## 保留原约束，限定声明范围

`GO_SEEDING_POLICIES` 保持原样，不删除、放宽或把未知阈值改成零。声明仅在当前下载器整行配置、准确 hash、下载器报告的任务新增时间、整组来源约束完全匹配时使用。已知最低累计做种时间与分享率仍须实时达标；未知实时计数、未完整下载、任务新增时间未知不能登记。记录后实时计数不得回退，重新添加、配置/来源变化、原操作者不再具有当前管理员下载权限、到期或撤销均失效。

最低要求仍未知或原 HR 标记仍保留时，声明明确由管理员承担“已在账户核实全部义务已满足”的判断，不伪装成自动站点证据或生成虚假的阈值。停止、删除、移动三项分别选择；未选择的动作继续拦截，未带动作的内部检查也不能使用声明。删除可能包含文件。原有账户权限、任务所有权、源/目标文件校验、独立操作确认及监控授权不被声明代替。

有效期为 1–30 分钟，界面提供 5/15/30 分钟。审核指纹绑定操作者、配置、来源集合、当前声明、准确新增时间、说明、动作及有效期，审核本身在五分钟窗口内有效。计数自然增长不改变指纹，但记录时重新获取真实计数作为后续回退基线，不接受客户端提交的观测值或阈值。

保存声明本身只写本地账本，不向下载器发停止/删除，不移动文件；但已启用且具备原权限及确认的自动流程可能立即继续所选动作。为此界面分别要求确认准确范围、站点账户核实、自动流程影响，以及旧 Go/Python 执行器已实际停止。不能在实现或测试时替用户勾选这些确认，也没有为真实任务写入任何声明。

## 审计、撤销和执行

`GO_PT_VERIFICATIONS` 追加不可变声明，`GO_PT_VERIFICATION_SCOPES` 指向当前记录，`GO_PT_VERIFICATION_REVOKES` 单独保留撤销者及时间。记录前后在事务中核对配置/来源及当前声明 CAS；旧记录和原约束不覆盖。只读查询、审核不建表。说明限制为 10–512 字，拒绝 URL/query 语法及控制字符；提示用户不输入 Cookie、口令或其他秘密。对外不返回原始下载器配置或私有下载地址。

记录、撤销、停止、删除与下载来源移动/恢复共用每任务跨进程锁。执行重新读取实时证据、声明、过期时间和操作者权限；只读结果不能用于后续跳过检查。已登记 qBittorrent 任务获准停止后使用版本选择的停止接口，不发送旧接口失败后再尝试新接口。声明不是对下载器自身或外部客户端的控制保证；过期和撤销不回滚已在执行中的操作。

管理员可在下载页只读刷新当前记录，单独审核并确认撤销。撤销不依赖下载器在线，不发送停止/删除、不清除来源政策。响应丢失只读刷新，不自动重发记录、撤销或任何任务操作。做种证据页面保留原约束检查，并逐动作标明是否依据 `operator-attestation`，不显示为站点自动核验成功。

新增时间只作任务身份比较，不参与最低做种时间计算。[Transmission 官方 RPC 规范](https://github.com/transmission/transmission/blob/main/docs/rpc-spec.md) 的 `added_date` / 旧协议 `addedDate` 与 qBittorrent 的 `added_on` 均保留缺失为未知。其他未支持的计数语义继续拒绝，不以人工声明补造实时数据。

## 剩余工作

站点专有账户级自动验证器仍未完成，不能因存在人工流程而宣称已自动验证 HR。原有“未知持续拦截”是默认；仅本模块独立声明可在明确范围及有效期内使用。高级订阅/媒体/云端等业务、完整生产请求链路/镜像验收及最终删除旧 Python 仍需继续；整体迁移仍粗估 50–60%。

## 集中验证（2026-10-16）

模块完成后，后端全量 `go test ./...`、`go vet ./...` 及 Linux amd64 无 CGO 静态构建通过。seeding、downloaderconfig、qbittorrent、transmission、organization 的竞态检测，以及 HTTP PT 核实、做种约束、PT 准入、下载器配置、下载、订阅执行/RSS、监控相关用例的竞态检测通过。撤销按撤销记录是否存在判断，补充了撤销时间字段为空仍不可恢复授权的回归用例。

前端 128 项测试全部通过，TypeScript 与生产构建通过；主包 530.80 kB，保留超过 500 kB 的非阻断拆包警告。上述验证使用临时数据库和模拟下载器，不代表真实站点账户、浏览器或生产环境验收，未对真实任务登记声明或执行停止、删除、移动。

Python 退出检查仍为 migration in progress：360 个 Python 源文件、13 处 Go legacy endpoint 调用计数、75 处 legacy proxy/runtime 引用、45 处容器 Python runtime 引用。这些计数不是功能完成率，不能据此宣称运行时已脱离 Python。
